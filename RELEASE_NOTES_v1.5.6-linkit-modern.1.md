# LinkIt ONE Arduino package v1.5.6-linkit-modern.1

This release provides an adapted LinkIt ONE package for newer Arduino IDE versions on Windows.

Included assets:

- `linkit-one-platform-1.5.6-linkit-modern.1.zip`
- `linkit-one-toolchain-arm-none-eabi-1.5.6-linkit-modern.1.zip`
- `linkit-one-tool-mtk-1.5.6-linkit-modern.1.zip`

Boards Manager URL:

`https://raw.githubusercontent.com/jaredsalazar/Linkitone_Arduino/main/package_linkitone-community_index.json`

Highlights:

- Adapted legacy LinkIt ONE platform for modern Arduino IDE package layout
- Bundled MediaTek uploader and ARM toolchain as Boards Manager tools
- Added compatibility fixes for modern builder paths
- Added `LED_BUILTIN` for the LinkIt ONE variant

Notes:

- Windows only
- Legacy board package, community-maintained
- Remove old manual installs before switching to the Boards Manager package
